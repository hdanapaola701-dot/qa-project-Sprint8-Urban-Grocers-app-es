🛒 Urban Grocers - API Testing

🔹 Descripción del proyecto
Este proyecto está enfocado en probar la funcionalidad de creación de un kit personal dentro de la plataforma Urban Grocers. 
Su propósito es validar el correcto funcionamiento de la API mediante pruebas automatizadas que contemplen escenarios  
tanto positivos como negativos, basados en la documentación oficial.

🔹 Objetivo
Automatizar pruebas para mejorar la calidad del sistema, reducir el tiempo de testing y asegurar resultados confiables 
antes del lanzamiento de la aplicación.

🔹 Documentación de la API: https://cnt-1a53e386-65dc-4b4d-9eee-630030c7e29b.containerhub.tripleten-services.com/docs/


🔹 Tecnologías utilizadas
Python como lenguaje principal, Requests para realizar llamadas HTTP, Pytest como framework de pruebas y JSON para el
manejo de datos.

🔹 Ejecución de pruebas
Primero, instala las dependencias necesarias:
pip install pytest requests

Luego, ejecuta todas las pruebas con:
pytest

🔹 Tipos de pruebas
Se incluyen pruebas positivas (creación correcta de kits y respuestas esperadas del sistema) y pruebas negativas 
(datos inválidos, campos faltantes y validación de errores controlados), lo que permite una cobertura más completa.

🔹 Resultado esperado
Garantizar el correcto funcionamiento de la API, detectar posibles fallos y asegurar la estabilidad del sistema bajo 
diferentes condiciones.

📌 Conclusión
Este proyecto busca fortalecer la calidad del producto mediante pruebas automatizadas, asegurando que la funcionalidad 
de creación de kits personales opere correctamente y cumpla con los estándares esperados.
